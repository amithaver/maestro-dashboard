# Живой дашборд «Реклама и брони» — сборка из BigQuery без LLM

Наряд 2026-11-02_1118. Страница: GitHub Pages `amithaver/maestro-dashboard` (адрес и пароль прежние).

## Обновить (три команды из этой папки)

```
python export_live.py                                   # BigQuery -> data_live.json (только чтение, по дням с 01.09.2026)
python check_live.py 2026-10-01 2026-10-31              # суммы = итоги, кампании = каналы, запрещённые слова, ПДн -> OK/FAIL
node build_page.mjs --encrypt <клон репо>               # page_plain.html + <клон репо>\index.html (зашифрован)
```
Потом в клоне репо: `git add index.html && git commit -m "Dashboard <дата>" && git push`.

- Пароль читается из файла `DASH_PW_FILE` (по умолчанию `C:\Users\Mesh\.secrets\maestro_dashboard_pw.txt`), нигде не печатается. Шифрование прежнее: AES-GCM, ключ PBKDF2-SHA256, 250 000 итераций. После шифрования скрипт проверяет расшифровку.
- `page_plain.html` — незашифрованная страница для локальной проверки. В репо её не класть.
- BigQuery: вход gcloud (`bq_util.py` в `Meta_BigQuery_2026-11`). Каждый запрос сначала проходит dry-run. Журнал — `_журнал_bq.csv`.

## Файлы
| Файл | Что делает |
|---|---|
| `export_live.py` | выгрузка по дню × отелю: реклама (витрина `ads_attr.bookings_from_ads` + отменённые с рекламой из `v_booking_touch`), показы и клики, касания, воронка GA4, источники броней сайта, брони по телефону, звонки `v_calls`, кампании |
| `campaigns_live.py` | кампании: расход из кабинетов, брони и выручка приведены к витрине (сумма по кампаниям отеля = канал отеля) |
| `page_template.html` | страница: фильтр дат «с — по» и отеля, кнопки «Все / Meta / Google» в блоке «Кампании». Всё суммируется в браузере из данных по дням |
| `login_shell.html` | экран пароля (как в прежней версии) |
| `build_page.mjs` | подставляет данные в шаблон и шифрует |
| `check_live.py` | проверки для гейтов |

## Правила на странице
- Только сайт и телефон. Брони — по дате создания, расход — по дате показа. Отмены не вычитаются, неоплаченные картой учитываются.
- ROAS ниже 1 — красным, черта на 1.
- Сравнение: если выбран целый месяц — с прошлым месяцем, иначе — с тем же числом дней перед периодом. Если в периоде сравнения нет броней по номеру (до октября 2026), изменения серые со звёздочкой.
- Звонки — только `v_calls`, без номеров звонивших. Блоки 2×2, матрица и пропущенные скрыты: в BigQuery нет журнала звонков с номерами.
